TechNova 쇼핑몰 데모
====================
- index.html : HTML/CSS/JS 인라인 단일 페이지
- img/       : 생성된 히어로 및 상품 이미지
- 실행: index.html을 브라우저에서 열기
- GitHub Pages: 저장소 루트에 index.html과 img 폴더를 함께 업로드한 뒤
  Settings > Pages > Deploy from a branch > main / root 선택
- 결제/회원 데이터는 브라우저 localStorage에 저장되는 데모입니다.
  실제 카드 결제, 배송, 보안 인증은 연동되어 있지 않습니다.
